# article reader (in #62)

hybrid rendering system that uses kernel `content_tree` (CommonMark format) via `ContentTreeBodyRenderer` to flatten prose into `NSAttributedString` segments displayed in `ArticleBodyView` (`UITextView`), with text selection via Edit Menu, footnotes via inline references, and reading progress overlay
